# H5 搜打撤 PVE · 3D 撤离射击

浏览器里跑的 **3D 搜打撤（Extraction Shooter）**，纯 PVE、单机、无联机无内购。
基于 **Three.js**，只针对桌面端 Chrome / Edge。

> 当前进度：**M5（局外系统）**
> M3 已落地一张 40×40、上下两层的室内图（地图表驱动）；M4 补齐了单局流程的完整闭环；
> **M5 补齐了"局外循环"**：主大厅（标签页）、仓库（格子 / 堆叠 / 排序 / 批量出售）、
> 配装（槽位 / 负重三档 / 预设）、商店（买卖价差 + 通胀监控输出）、等级与技能树（含洗点）、
> 任务线（收集 / 击杀 / 撤离 / 开箱 / 估值五类目标）、**带版本与迁移的存档**（含异常恢复），
> 以及设置（画质三档 / 音量分轨 / 改键）。
> 核心闭环：**大厅配装 → 进战区（配装从仓库取走）→ 搜刮交战 → 撤离（没用完的还回仓库）
> 或阵亡（整套行装丢失）→ 结算落库（经验 / 任务 / 仓库）→ 回大厅**。

## 立刻玩（不需要装任何东西）

**[下载免安装包](release/H5-SDC-PVE-M5.zip)** → 解压 → 双击 `game.html`。
（或直接到 [Releases](https://github.com/aaaa26666/h5sdc/releases) 页下载 **[v0.0.4](https://github.com/aaaa26666/h5sdc/releases/tag/v0.0.4)**。）

- 不需要 Node.js、不需要联网、不需要安装
- 整个游戏是**一个自包含的 HTML 文件**（约 639 KB）
- 所有素材都是程序生成的（音频用 Web Audio 合成、贴图用 canvas 生成、无外部模型），
  所以单文件就是完整游戏

### 操作

| 动作 | 按键 |
|---|---|
| 移动 / 视角 | `W A S D` · 鼠标 |
| 射击 / 开镜 | 鼠标左键 · 鼠标右键（按住） |
| 切枪 / 换弹 | `1` 主武器 · `2` 副武器 · 滚轮 · `R` |
| 奔跑 / 蹲下 | `Shift` / `C`（设置里可选「按住」或「切换」） |
| 跳跃 | `Space` |
| 左右探头 | `Q` / `E`（按住；射击从探头位置出膛） |
| 搜索容器 | 靠近后按住 `F` |
| 医疗 | `3` 绷带（未满血即可用，回 18）· `4` 急救包（回 65；受击会打断） |
| 暂停 / 设置 | `Esc` 解锁鼠标后打开 |

**玩法目标**：进入战区 → 搜刮容器 → 与 AI 交战 → 带着战利品走到撤离点撤离。
本版地图有**四个撤离点**，规则各不相同：

**局外循环**（M5）：大厅里配好这一局要带的东西（**装备从仓库取，用了要还、死了就丢**），
按预设进战区；撤离成功则战利品与没用完的配装回到仓库，阵亡则整套行装丢失（只有保险箱里的保住）。
返回大厅后可以整理仓库、买卖物资、点技能、接任务；**任务要一段一段来 —— 前置任务完成并
领取奖励之后，下一段才会解锁**。进度存在本机档案里（带版本与迁移，重开浏览器不丢）。
新账号**仓库是空的**——先去商店买一套基础装备再进战区。

| 撤离点 | 位置 | 开放条件 |
|---|---|---|
| 安检出口 | 一层 | 常驻 |
| 天台门 | 二层 | 常驻 |
| 货运装卸口 | 一层 | 局内时间过半后开放 |
| 档案库紧急出口 | 二层 | 累计淘汰 3 名敌人后开放 |

撤离区**绿色 = 可用、灰色 = 未开放**（站在灰圈里会提示还差什么）。倒计时 10 秒，
期间**离开撤离区**会中断（宽限 0.5 秒）；受击、开火、治疗都**不会**中断。
撤离成功战利品才归你；阵亡、超时或主动放弃则只保住**保险箱**里的。
刷新或关闭页面视为"未撤离"：下次进来会给出上局结算，不会静默丢档。

**已确认的欠账**（不想让它看起来比实际更完整）：
- **M5 的全部数值都未经试玩标定**：等级曲线、技能效果、负重三档阈值、任务目标与奖励、
  买卖价差、经济价差都是"看起来合理"的取值。机制正确性有断言守着，**手感与平衡没有依据**。
- **新账号仓库是空的**（制作人裁定）：起始货币 20000 但没有任何装备，必须先去商店买，
  否则会赤手空拳进战区（允许缺件进局，且**刻意不做缺件提示**）。
- **触屏不可玩**：触屏控件属 M8，M5 只保留设置项与能力检测的位置。
- **弹药与消耗品不占背包格子**（`M5-TEMP-11`）：制作人的原始意图是"只要格子塞得下"，
  当前实现是"不设数量上限但仍是不占格的数字"。
- **装备没有耐久持久化**（`M5-TEMP-9/10`）：每次进局护甲满耐久、武器满弹匣。
- **掩体仍是手摆的灰盒**：地图表里 47 个掩体矩形（34 个低 0.45m / 13 个高 1.05m），
  放在 `src/config/maps/*.json` 里而不是随机生成。它足以验证台阶与掩体机制，
  **但不是关卡设计**（通路、视线通道、高低差层次都还没做）。
- AI 不会蹲下、不会探头、不会利用掩体高度 —— 玩家在掩体对抗中单方面占优。
- 台阶吸附只做**上行**平滑，走下掩体是直接落体。
- 无弹道下坠与飞行时间；无配件系统；无角色动画。
- 音频无距离分层与遮挡（所有枪声都从玩家位置发出）；音效是程序化合成，不是正式素材；
  音乐轨已接上总线但**没有 BGM**（属 M7）。
- **移动手感从未被真人试玩过**：参数被量化、方程被单测覆盖 30~360Hz 七档帧率，
  但"这些数值好不好玩"是另一回事。
- **AI 出生点都在一层**（`M3-TEMP-7`）：二层开局是空的，AI 会自己沿楼梯上来
  （实测约 18~23 秒）。二层容器数与一层相当，因此开局那段"上楼"是零风险高收益。
- **首包体积余量只剩约 15 KB**（184.6 / 200 KB brotli）：M6 扩充内容前必须先决定
  放宽预算还是做代码分割。

## 已知问题

**1. `Shift + D` 可能触发浏览器的「多选下载」**

某些下载类浏览器扩展把 `Shift+D` 注册成了下载嗅探快捷键，而本游戏的
「冲刺 + 右平移」正好是这个组合。经查是 **「迅雷下载支持」** 扩展在内容脚本里写的：

```js
switch(e.keyCode){ case 68: e.shiftKey && (…) }   // 68 = 'D'
```

它以 `run_at=document_start` + 捕获阶段注册监听，**跑在页面脚本之前**，
因此网页侧无法可靠拦截。处理办法：在浏览器扩展管理里停用/移除这类下载扩展。

**2. 不要使用 `Ctrl` 组合键**

`Ctrl+W` 等是浏览器保留快捷键，网页无法拦截，会直接关掉标签页。
游戏本身没有把任何 `Ctrl` 组合绑定为操作键，并有自动化审计守住这条规则。

## 本地开发

需要 **Node.js 18+**。

```bash
npm install
npm run dev          # 开发服务器（含调试接口，可用自动化测试驱动）

npm run build        # 生产构建 → dist/
node tools/build-portable.mjs   # 免安装单文件包 → release/
```

## 质量保障

所有验证都是**可执行脚本**，不是人工 checklist：

```bash
node tools/unit-tests.mjs                          # 纯逻辑单测            477 项
node tools/smoke.mjs                              # 端到端（含连续10局）  221 项
node tools/smoke.mjs --only=m5                    # 只跑 M5 段落（改一行即可快速验证）
node tools/validate-loot-tables.mjs               # 掉落权重表校验         36 项
node tools/render-map.mjs --floor 0 / --floor 1    # 动线图与地图校验（每层 11 项）
node tools/ttk.mjs                                 # 手感量化报表 + 设计目标判定
node tools/audit-keybindings.mjs                   # 按键审计（禁用修饰键、禁止重复绑定）
node tools/economy-report.mjs                      # 经济与通胀监控输出（带退出码）
node tools/verify-prod-bundle.mjs                  # 验证调试接口已从生产产物剔除
node tools/measure-bundle.mjs                      # 首包体积门禁（预算 200 KB brotli）
node tools/test-portable.mjs                       # 便携版在 file:// 下真的能玩
node tools/capture-level-golden.mjs --map industrial_01 --verify results/level-golden-industrial_01.json
                                                   # 几何行为黄金基准（92012 条逐条比对）
```

**所有测试默认无头（headless）运行** —— 有头模式下指针锁定会抓走鼠标并抢占窗口焦点，
跑测试期间电脑基本没法用。需要人眼旁观时加 `--headed`。

已实测确认无头下走的是**硬件** GPU（ANGLE/D3D11，约 122fps，不是软件渲染）、
指针锁定可以成功、CDP 输入照常生效，因此测试结论与有头一致。
（例外：`m1-perf.mjs` 的帧时间不能与 M0/M1 的**有头**基线直接混比 —— 合成路径不同。）

几个工具存在的理由值得单独说：

- **`audit-keybindings.mjs` 会注入 bug 自检**：它先在内存里造一个违规绑定，
  确认自己会报错，再去检查真实配置。一个从不失败的检查等于没有检查。
- **`verify-prod-bundle.mjs` 扫描产物字符串**，而不是依赖「我以为 tree-shaking
  会把它摇掉」。调试接口用 `import.meta.env.DEV` 门控，该脚本负责证明它真的没了。
- **`test-portable.mjs` 用默认 Chrome 参数**、不加任何 `--allow-file-access-from-files`
  之类的开关，因为别人机器上也不会有。

## 技术要点

- **Three.js 0.186** + **Vite 8**（rolldown/oxc）
- **数据驱动**：武器 / 护甲 / AI 难度全部在 JSON 表里，代码只做解算
- **配置约定**：以 `_` 开头的键是注释，遍历一律经 `dataKeys()` 过滤
- **路径查询限流**：所有 A\* 查询经过预算调度器，实测峰值恒为 2 次/帧、0.4 ms/帧
  （无限流时最坏帧曾达 68 ms）
- **玩家与 AI 共用同一套伤害解算**，不存在「打我和打 AI 数字不一样」
- **调试接口用 `import.meta.env.DEV` 门控**，生产产物中经扫描确认已完全剔除
